About

I'm Amir Homayoun Esmaeili (Persian: امیر همایون اسمعیلی), an Iranian programmer and software engineer. My main website and full portfolio is amirhomayoun.ir. I build fast native tools for Windows and Android with Rust, Tauri, .NET and Electron, full-stack web platforms with Next.js, Node.js and PostgreSQL, and games for PC and Android. I also work on technical SEO, and I publish free, open-source tools that make Persian work properly on computers: Jalali dates, right-to-left text, Persian keyboards and subtitles.
